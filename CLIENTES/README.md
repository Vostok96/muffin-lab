# CLIENTES

Esta carpeta almacena insumos de branding por institución: logos, emblemas, capturas de referencia visual, paletas o documentos de identidad.

Reglas:

- No guardar datos clínicos, pacientes, órdenes ni resultados.
- No versionar fotos de usuarios, firmas, documentos personales ni medios biométricos.
- No guardar credenciales ni archivos `.env`.
- No cargar estos assets automáticamente en MUFFIN padre.
- Cada institución debe tener su propia subcarpeta.
- La activación de un branding institucional debe hacerse en una rama, fork o paquete de despliegue específico.

La carpeta actual contiene insumos visuales de referencia para una futura variante institucional.
